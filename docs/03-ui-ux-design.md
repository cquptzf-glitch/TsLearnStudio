# TsLearnStudio UI/UX 设计规范

- 版本：v0.2
- 定位：学习工具优先，逐渐解锁专业 IDE 能力
- 默认主题：亮色；支持暗色、系统跟随
- 目标显示器：Windows 11，1920×1080、1366×768、125%/150% DPI

## 1. UX 原则

1. **单一主任务**：默认界面突出当前课程与下一步操作。
2. **讲解与实操同时可见**：学习工作台左侧讲解、右侧代码与结果；可拖动分隔。
3. **反馈可解释**：失败要说明错误类型、来源位置、下一步，不以红色标记代替说明。
4. **可逆操作**：重置、删除、切换任务导致丢失草稿时需确认并可恢复。
5. **渐进复杂性**：单课无需暴露完整文件树、终端和服务配置；项目模式开放。
6. **不伪造能力**：无法真实运行时显示环境尚未配置/不可用，不生成假的“测试通过”。
7. **知识优先**：课文、代码、流程图与实验结果的相互对应明显。
8. **工程师友好**：C++/Qt 类比卡可开启/关闭，讲解关键运行语义而非重复通用语法。

## 3. 布局系统与视觉风格

### 3.1 桌面导航布局
- 顶栏：高度 53px；应用标题、当前课程、搜索、主题切换、设置入口。
- 左侧全局主导航：宽 202px；支持收缩到 61px 图标模式；底部设置/帮助。
- 工作区域：自适应；内容区设计最小宽度约 760px（更窄时显示单栏模式）。
- 右侧工作台：课程解释宽 42%（允许 32%–65% 拖动），代码宽 58%。
- 代码区上下：编辑器约 65%、运行与测试面板约 35%；可拖动。
- 所有可拖动面板保存尺寸；窗口小于建议尺寸时使用 Tabs 切换讲解/代码/结果。
- 优先无干扰：课程阅读时可折叠全局导航。

- 字体：Segoe UI / system-ui；代码 Cascadia Code / Consolas / monospace。
- 尺寸：内容字号 14px–16px、说明 12px–13px、主标题 22px–28px。

## 4. 页面详细设计

### P-01 学习首页

~~~text
┌ 顶栏：TsLearnStudio / 搜索 / 主题 / 设置 ───────────────────────┐
│ 侧栏导航 │ Welcome back！                                   │
│          │ ┌──────────────────┐ ┌────────────────────────┐ │
│ 首页     │ │ 继续学习          │ │ 今日建议：2 个任务     │ │
│ 课程     │ │ TS 异步编程       │ │ 复习 Promise           │ │
│ 练习     │ │ [继续]            │ │ 修复 fetch 错误        │ │
│ 项目     │ └──────────────────┘ └────────────────────────┘ │
│ 成长     │ 阶段进度：Web / JS / TS / React / Node / 实战       │
│          │ 最近尝试 / 错题回顾                               │
└──────────┴──────────────────────────────────────────────────┘
~~~

交互：继续学习导航至上一次 Lesson+Step+草稿；未开始时提示第 1 课；点击阶段进入目录；无记录时明确空状态。

### P-02 课程目录

卡片或列表按六个阶段组织：阶段名、目标、预计学时、完成数量、先修建议；可筛选「未开始/进行中/已完成」和关键字检索。点击课程打开详情，不直接改变完成状态。允许访问后续课程但展示建议先修课。

### P-03 学习工作台（产品核心）

~~~text
┌ 课程路径 / 上一节 / 下一节 / 概念 | 演示 | 实践 | 测验 ─────────┐
│ 课程讲解（可拖动宽度）     │ main.ts  | 测试说明            │
│                           │ ┌────────────────────────┐ │
│ 目标 / 理论 / 代码对照     │ │ Monaco + 类型诊断       │ │
│ 可折叠 C++/Qt 对比         │ │                         │ │
│ 流程动画与说明             │ └────────────────────────┘ │
│ 难点提示 / 思考题          │ ▶运行  ■停止  提交  重置   │
│                           │ 控制台 | 诊断 | 测试 | 帮助│
└───────────────────────────┴─────────────────────────────┘
~~~

状态：
- 课程未开始：简介、预计时间、开始按钮。
- 阅读中：当前 Step 左侧突出，代码示例可复制/导入工作区。
- 编辑未保存：状态条点标记、自动保存完成后变为「已保存」。
- 类型错误：Monaco underline + Diagnostics 中列出具体位置、错误码、建议阅读点。
- 运行中：运行按钮不可重复点击，停止可用，结果面板展示事件流。
- 运行失败：明确编译/运行时/测试失败，不自动修改代码。
- 已通过：显示通过的断言数、耗时、能力标签与下一步；不自动跳下一课。
- 缺少环境：操作禁用并显示「检查运行环境」链接。
- UI 原型模式：所有结果都标记为示例，不能假装运行代码。

### P-04 综合项目工作台

模式切换顶部为「学习模式 / 项目模式」；项目左侧文件树 + 任务列表二选一；中间多文件 Monaco；右侧可切换预览、HTTP 请求、项目说明；下方可折叠终端/诊断/测试。

项目最小任务链：
1. 创建数据模型。
2. 实现 API 接口。
3. 增加 React 列表。
4. 加入筛选/新增/修改。
5. 写测试和修复两处故意引入的缺陷。
6. 通过总体验收。

项目模式的「安装依赖」「运行脚本」必须经过权限检查和用户确认；在主界面标出本地服务状态及端口。

### P-05 学习进度

上方：总完成度、最近学习日期、累计练习次数、成功率。
中间：六个阶段的课程状态；掌握度以知识点而非单一分数展示。
底部：作业提交历史、错题分类、建议复习课；可打开失败尝试直接定位作业。
无进度时显示「完成首节课后查看详细统计」。

### P-06 设置与环境

- 外观：亮色/暗色/系统跟随、代码字号、界面缩放、减弱动效。
- 环境：Electron 版本、Node 运行器可用性、TypeScript 编译器、npm/pnpm、Vite、可用端口和缓存状态。
- 数据：工作区位置（首版固定在 userData 下）、导出备份、清理缓存（需确认）。
- 隐私：是否启用可选 AI、传送哪些上下文、如何撤销。
- 诊断：日志级别、导出脱敏日志、异常恢复。

## 6. 核心交互规则

- 重要按钮永远出现在编辑器上方固定工具栏（运行、停止、提交、重置）。
- 键盘建议：Ctrl+Enter 运行、Ctrl+Shift+Enter 提交、Ctrl+S 保存、Ctrl+K 搜索（避免 Monaco 默认快捷键冲突；最终统一核验）。
- 课程左右切换保留滚动位置、光标和编辑草稿。
- 输出 Tab 采用「Console / Problems / Tests」；发生致命运行错误时自动提示但不强迫切换当前焦点。
- 对长期运行任务提供取消；UI 关闭时至少终止本次任务进程树。
- Undo/Redo 只作用于编辑器；工作区重置通过独立快照策略恢复。
- 不能在测试未结束时给出「已通过」的最终结论。
- 帮助提示采用分级揭示：概念 → 关键位置 → 方案提示 → 完整参考（最后一级二次确认）。

## 7. 空状态/异常状态矩阵

| 位置 | 空状态 | 错误状态 | 恢复 |
| --- | --- | --- | --- |
| 首页 | 尚未学习 | 进度读写失败 | 重试/查看存储路径 |
| 课程 | 无匹配 | 内容包不兼容 | 重置筛选/修复课程包 |
| 编辑器 | 尚未打开题目 | 工作区不存在 | 重建工作区并保留快照 |
| 运行面板 | 尚未运行 | TS 诊断/超时/崩溃 | 重新运行/环境检测 |
| 测试面板 | 无提交 | 断言失败/测试设施错误 | 定位代码/重新评测 |
| 项目预览 | 服务未启动 | 地址不可达/权限拒绝 | 启动服务/检查端口 |

## 8. 响应式、可访问性与 Windows 交互

- 小窗口：左右分栏改为切换标签；保留运行与提交入口。
- 高 DPI：使用 CSS 像素和弹性布局，不依赖固定屏幕分辨率。
- 文本 200% 放大仍可找到核心控制；支持焦点高亮与键盘 Tab 顺序。
- 图标与工具栏按钮提供可读名称、悬停说明；任何按钮必须有行为，不放装饰性假按钮。
- 动态测试结果采用 aria-live="polite"（错误可升级）。
- 快捷键冲突有设置入口说明。
- 深浅主题分别检查 Monaco 配色和代码 diff 对比度，统一含新增/删除语义。
- 兼容触控板滚动、鼠标横向分隔拖动、窗口最大化/还原。

## 9. UI 原型验收

[prototype/index.html](../prototype/index.html) 用于验证：
- 全局导航与阶段切换；
- 课程页面布局、讲解+编辑器+结果区分栏；
- 暗色/亮色主题切换与保存到当前浏览器会话；
- 课程目录、练习、项目与进度页面的主要信息层级；
- 原型上的「运行」「提交」只显示原型解释，不执行代码或产生真实评测结果。

原型的 CSS/JS 仅为视觉草案，不代表最终 React 组件或 Electron 业务已交付。

## 10. v0.2 专业紧凑型工作台优化（2026-10-31）

### 10.1 设计目标与改动
v0.1 存在首页卡片大、留白过多、页面内容偏浅、工作台难以同时看全说明/代码/输出、各页面信息层级不统一等问题。v0.2 采用「桌面工具栏 + 双层导航 + 数据密集工作区 + 可见状态反馈」设计，强调工程师效率和专业性。

- 主界面缩小留白，统一 8px 基础间距、9–13px 圆角、单像素中性分割线。
- 全局导航固定 202px、窄屏 61px；顶栏 53px；原型提示独立成 34px 条，始终明确缺失能力。
- 正文字号 13px、二级正文 12px、列表标签 11px；提供适中行高，密度提高不牺牲可读性。
- 色彩以中性灰蓝和功能蓝为主；成功/危险色只用于真实语义状态，原型页面不显示虚构成绩。
- 内容区不以大卡片装饰为目的；课程、练习、运行状态使用表格与分层面板。
- 采用统一小工具条和 page header，使主操作固定位置、易于扫描。

### 10.2 七个页面在 v0.2 的实际设计

| 页面 | 内容密度与布局 | 原型当前可操作项 |
| --- | --- | --- |
| 学习概览 | 继续学习区域 + 今日步骤 + 四项规划指标 + 六阶段条带 + 练习表格 | 页面导航、进入课程/练习、阶段跳转 |
| 课程体系 | 左侧模块目录（6 阶段），右侧课时表格（48 课） | 选阶段、按模块内关键词筛选、全局搜索 |
| 学习工作台 | 顶部四步骤；左侧详细教程，右侧文件 Tab、代码编辑、运行工具条、输出 Tab | 步骤切换、编辑两份 TS 样例、局部草稿保存、布局比例切换 |
| 练习与作业 | 四项规划指标、表格任务清单、右侧评测闭环说明 | 查看任务规划、打开 JS-08 示例 |
| 项目实战 | 左文件树、中示意代码/终端、右 8 项里程碑 | 查看阶段实施说明 |

### 10.3 学习工作台微交互

- 编辑区域为**原型 textarea + 行号同步**；正式工程实现替换为 Monaco Editor，不能把原型当作完整 IDE。
- 示例文件标签：loadUser.ts / types.ts。切换文件保留各自草稿；Ctrl+S 保存浏览器本地，Ctrl+Enter 可触发「未接运行器」提示。
- 运行工具条顺序：运行、提交评测、重置、草稿状态；重置前需确认。
- 输出面板四个 Tab：控制台、问题、测试结果、HTTP 请求；每个未实现功能均返回清晰提示。
- 课程内四步骤：概念讲解、执行流程、动手练习、回顾总结；练习支持分步提示，选择题可提供明确标为「原型反馈」的即时判断（不记入进度）。
- 讲解区：学习目标 → 核心概念 → C++/Qt 对照 → 可运行示例说明 → AI 常见误区 → 练习验收。
- 面板宽度：默认约 42:58，切换到 52:48。正式版需实现拖动、宽度持久化及窄窗口响应式降级。

### 10.4 状态规范
- **原型状态**：导航与外观立即生效；草稿存入浏览器 localStorage，但不会写入 SQLite/工作区；关闭或清除浏览器数据后可能丢失。
- **编译/运行状态**：在未集成 TypeScript Compiler API、Node Runner 前，只显示「未执行」，禁止伪造测试通过、错误清单与分数。
- **进度状态**：未完成真实数据接入前采用「— / 未评分 / 待接入」表达，不使用看似真实的完成率。
- **任务状态**：48 个课程属于「规划目录」；只有 JS-08 有完整的工作台示例正文，其他课程点击时说明尚未制作。
- **项目状态**：项目模式文件树、代码和终端为只读布局样例，不代表真实后端已经启动。

### 10.5 视觉与交互验收补充
- 1366×768 窗口内能同时识别课程讲解、编辑工具、代码和输出区域。
- 1920×1080 下不出现一行长幅空白、过宽正文；关键操作在顶部可见。
- 窄窗口侧栏可压缩；800px 以下工作台改为纵向布局。
- 所有 Tab、导航、搜索、重置、提示、主题、字号均由真实事件控制，而非仅装饰。
- 无障碍与键盘焦点可见，参考控制对比度；正式版还需 Playwright 截图回归和高 DPI 测试。
- 原型为纯静态三文件：index.html + styles.css + app.js；无需编译，下载整个 prototype 文件夹后直接打开 index.html。
